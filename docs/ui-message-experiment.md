# MCP Apps ui/message — эксперимент v0.2.15

## Цель
Инициировать обработку сообщения из локального окна ChatGPT MCP Tunnel в обычном ChatGPT только средствами MCP Apps ui/message. Без Codex, Work, отдельного API, автоматизации браузера или запуска модели планировщиком.

## Механизм
- MCP-инструмент chat.ui.open имеет _meta.ui.resourceUri=ui://chatgpt-mcp-tunnel/relay и точку входа openai/ui (global, thread).
- Ресурс возвращается через resources/read с MIME text/html;profile=mcp-app. Весь сценарий встроен в файл ChatRelayApp.html.
- Компонент устанавливает связь ui/initialize. Пользователь явно нажимает «Начать передачу».
- Компонент опрашивает chat.ui.pending посредством tools/call, затем отправляет ui/message с ролью user и параметрами openai/message target=active, send=true.
- При успехе выполняется chat.ui.ack, создающий отдельный файл подтверждения в LocalAppData/ChatGPTMCPAgent/Chat/ui-forwarded. Исходное сообщение, ответы и вложения не меняются. Отказ хоста сохраняет сообщение для повторной попытки.
- Для ответа модель использует chat.reply, а для прочтения вложений — chat.attachment.read.
- Закрытие компонента останавливает цикл. Никакого прямого обмена с закрытым ChatGPT сервер не обещает.

## Проверки
- Сборка .NET, метаданные tools/list и ресурс resources/read: tests/test_chat_ui_mcp.py.
- Имитация действующего хоста MCP Apps с отправкой ui/message, подтверждением после успешного ответа, отказом без подтверждения и прекращением опроса: node tests/test_chat_ui_bridge.js.
- Регрессионные проверки остальных MCP-инструментов и Router Lite.

## Обязательная практическая приёмка
1. Установить выпуск, обновить перечень инструментов подключённого плагина.
2. В обычном ChatGPT открыть chat.ui.open, нажать «Начать передачу».
3. Отправить сообщение из локального окна, проверить приём ui/message настоящим ChatGPT без дополнительного нажатия.
4. Убедиться, что модель вызвала chat.reply, а ответ отображается в локальном чате.
5. Проверить остановку при сворачивании/закрытии компонента и восстановление.
Это эксперимент: тестовый имитатор не доказывает, что хост ChatGPT разрешает автоматический вызов ui/message после задержки. Хост может отклонить запрос или потребовать подтверждение.
