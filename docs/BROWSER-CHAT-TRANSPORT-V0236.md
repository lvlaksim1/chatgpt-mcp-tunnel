# ChatGPT MCP Tunnel v0.2.36 — автономный браузерный транспорт (экспериментальная версия)

## Назначение
После однократной авторизации пользователя в отдельном профиле Yandex Browser сообщения из локального окна туннеля автоматически отправляются в **обычный ChatGPT** и ответы сохраняются в исходном локальном чате. Нет отдельных API-ключей, Codex, Work или необходимости вызывать `chat.ui.open` для каждого сообщения.

## Архитектура
- Агент запускает собственный `OpenAI/node.exe`, который исполняет `Runtime/BrowserChatBridge.js`. Node входит в установочный пакет.
- Рабочий браузер запускается с независимым `user-data-dir` внутри `%LOCALAPPDATA%/ChatGPTMCPAgent/Chat/dedicated-browser-profile`, через CDP исключительно на `127.0.0.1` со случайным портом.
- При первом запуске пользователь один раз входит в ChatGPT в появившемся окне. Далее профиль сохраняет сессию; никаких паролей туннель не читает и не хранит.
- Исходящий текст отправляется напрямую в визуальный редактор сайта; никаких скрытых API-вызовов к модели, технических подсказок и служебных идентификаторов в текст чата не добавляется.
- Для новых локальных чатов облачная беседа создаётся автоматически. После подтверждения URL вида `https://chatgpt.com/c/<uuid>` создаётся постоянная локальная привязка.
- Для существующего локального чата с известной проверенной привязкой используется прежняя облачная беседа. **Для старых чатов без такой привязки новая беседа не создаётся автоматически**, чтобы не нарушить требование пользователя.
- За доставку отвечает один транспорт: периодический heartbeat браузерного воркера блокирует старую MCP Apps-очередь, а файл `browser-claims/<message-id>.json` защищает от дублирования после неопределённого ответа.
- Если модель ответила, текст фиксируется в исходном JSON-сообщении со статусом `answered`. После аварийного перезапуска отправленные сообщения по возможности восстанавливаются из подтверждённого облачного диалога.
- Работает без вмешательства в основной профиль Yandex Browser.

## Проверки перед приёмкой
- Сборка .NET, чистые пакеты, тесты структуры и UTF-8; повторяемый heartbeat при отсутствующей очереди.
- Обнаружение подтверждённого окна ChatGPT и реальная отправка/получение ответа — **пока не проверены в авторизованном профиле**, необходимо испытать после однократного входа.
- Приёмка: два последовательных сообщения в новом чате, затем существующий чат с установленной привязкой, перезапуск процесса, сохранность ответов.
- Вложения пока остаются в локальной очереди и не теряются; загрузка вложений новым браузерным транспортом ещё не реализована.

## Безопасность
Не использовать сохранённые профили сторонних браузеров, не копировать cookies, не обходить вход и CAPTCHA, не публиковать профиль браузера и пользовательские файлы в GitHub. Не показывать браузерный CDP-порт наружу. Сохранять резервную копию установленной версии при обновлении.
