# Локальная разработка ChatGPT MCP Tunnel

Основное рабочее дерево: D:\Dev\ChatGPT-MCP-Tunnel на DOMKAT.

## Роли

- DOMKAT: исходники, компиляция .NET, тестирование Windows, создание Inno Setup установщиков.
- GitHub: хранение исходников, история Git и размещение готовых файлов релиза.
- GitHub Actions: отключены и не используются для сборки, тестирования и публикации.

Рабочий установленный туннель: D:\ChatGPTMCPAgent. Его не заменяют во время сборки.
Старый рабочий репозиторий: D:\ChatGPT-MCP-Tunnel. Он не является основной средой разработки.

## Локальный выпуск

Запускать из PowerShell на DOMKAT:

    Set-Location D:\Dev\ChatGPT-MCP-Tunnel
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-LocalRelease.ps1 -Version 0.2.27

Зависимости: .NET 8 SDK, Python 3, Inno Setup 6, проверенный tunnel-client в установленном туннеле.

Скрипт создаёт автономные Windows-сборки, прогоняет локальные тесты, компилирует полный и обновляющий установщики.
Результаты и SHA-256 находятся в .tools\local-release\vX.Y.Z\dist.
Выпуск не устанавливается на рабочий компьютер автоматически.
Папка уже готового выпуска не перезаписывается без явного решения разработчика.

После успешной локальной проверки: обычный Git push исходников и прямая загрузка готовых установщиков через GitHub Releases API. GitHub Actions не запускать.

Тестирование установки поверх рабочего приложения требует отдельного безопасного сценария и не входит в локальную сборку.

## СТОП

Кнопка СТОП блокирует управляющие MCP-команды. Длительные локальные сценарии запускаются отдельно: при создании фоновых процессов необходимо предусматривать способ их остановить.
