# UAC по запросу — ChatGPT MCP Tunnel v0.2.42 (30.10.2026)

## Назначение
Постоянные процессы ChatGptMcpAgent и ChatGptMcpTunnel работают с обычными правами пользователя. Для административной операции через существующий MCP-инструмент `shell.exec` передаётся `elevated=true`. По умолчанию `false`.

## Последовательность
1. Модель или оператор вызывает `shell.exec` на DOMKAT или подключённом компьютере с `elevated=true`.
2. Целевой компьютер вызывает Windows UAC для отдельного экземпляра установленного `ChatGptMcpTunnel.exe --elevated-shell <случайный-идентификатор-канала>`. Текст команды не передаётся в параметрах этого процесса и не записывается в файл.
3. После одобрения UAC одноразовый повышенный процесс получает запрос через локальный именованный канал (случайное имя), запускает PowerShell либо CMD с повышенными правами и возвращает код, stdout/stderr, время и признак тайм-аута.
4. По окончании одноразовый процесс завершается; постоянно запущенные агент, Router Lite и MCP-сервер не повышают права.

Повышение требует интерактивного подтверждения пользователя Windows **на целевом компьютере**. В удалённом сеансе без доступного рабочего стола запрос может завершиться ожиданием/ошибкой. Отмена UAC не приводит к исполнению команды. Удалённые маршруты Router Lite получают тот же `elevated` и не подменяют целевой компьютер.

## Ограничения и безопасность
- Повышение является **явным** на каждом административном вызове `shell.exec`; автоматического запуска туннеля администратором или фонового постоянного привилегированного сервиса нет.
- Привилегированная оболочка выполняет указанную команду в рамках полученного после UAC доступа. UAC не показывает полный текст команды: перед одобрением нужно понимать операцию и доверять вызывающему агенту.
- Локальный STOP отменяет ожидание ответа и закрывает канал; помощник прекращает дочерний процесс при обнаружении обрыва. Это не гарантирует отмену отдельно запущенных процессов или уже совершённых системных изменений.
- Параметры `fs.write`, `process.kill` и других прежних MCP-инструментов не превращены автоматически в привилегированные: административные файловые/процессные/системные операции теперь доступны через `shell.exec` с `elevated=true`.
- При повышении через ввод учётных данных **другого** администратора разрешения канала требуют проверки на конкретной машине; поддержка этого сценария ещё не принята.
- Секреты не передавать в командных строках/логах. Ранее действующие требования ограничения доступа к самому MCP Tunnel остаются в силе.

## Интерфейс
Из меню трея удалён пункт «Индикатор управления / СТОП». Сам индикатор активности автоматически появляется при операциях; кнопка STOP и её логика остаются.

## Проверки
- Компиляция Runtime и WinForms Agent; локальная проверка связи и выполнения команды через именованный канал без UAC; проверка неверного идентификатора помощника.
- MCP tools/list содержит `shell.exec.elevated`, обычные команды по умолчанию не повышаются, тесты управления, Router Lite, Unicode и Windows MCP.
- Проверка с реальным UAC на установленной версии требует подтверждения пользователя Windows; в процессе автоматической сборки UAC **не нажимается**.
