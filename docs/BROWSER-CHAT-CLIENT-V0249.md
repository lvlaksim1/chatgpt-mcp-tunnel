# ChatGPT MCP Tunnel v0.2.49 — WebView2/Happ и новый интерфейс

31.10.2026, MSK. Разработка ведётся локально на DOMKAT.

## Функции и архитектура
- Главное окно: чат ChatGPT (появляется при обычном запуске), версия в заголовке.
- Меню трея: «Настройки», «Выход»; подсказка трея только статус подключения.
- Настройки: подключение, переподключение, UAC, уведомления, выбор тёмной/светлой темы, файлы, обновления.
- Административные операции через отдельный стандартный UAC, а не постоянный запуск всего приложения с повышенными правами.
- Темы: единые цвета WinForms, заголовков, скроллбаров и служебных уведомлений; настройки хранятся отдельно от ключей сети.
- Установщик и обновлятор: переключатель с запросом UAC, перед заменой файлов --shutdown через IPC, ожидание штатного выхода агента.
- Транспорт: C# WebViewChatHost, WebView2 с единым профилем, встроенный Chrome DevTools Protocol, облачные беседы /c/<uuid>, очередь и привязки сохраняются. Node/внешний Chromium исключены из установки.
- Никаких сторонних дополнительных туннелей, API-ключей для чата, Work или Codex.

## Сетевой маршрут
- Установленный Happ предоставляет HTTP-прокси 127.0.0.1:10809 и SOCKS5 127.0.0.1:10808.
- Системный WinINET/WinHTTP прокси отключён; прямой curl к chatgpt.com завершается тайм-аутом.
- HTTP и SOCKS5 прокси проверены curl; оба достигают chatgpt.com через Happ.
- WebViewNetworkProxy выбирает локальный HTTP, затем SOCKS5, иначе прямой маршрут.
- WebView2 получает только процессный Chromium аргумент --proxy-server. Системные настройки и Happ не изменяются.
- Тест --test-webview-network-live создал изолированный профиль WebView2, загрузил chatgpt.com и завершился с кодом 0. Этот тест не использует пользовательские cookies.

## Оставшаяся приёмка
- В новой версии браузерный профиль WebView2 требует однократной интерактивной авторизации на странице ChatGPT.
- Нужен реальный E2E после входа: новое сообщение, ответ, продолжение того же URL после перезапуска.
- Также требуется нагрузочная приёмка, вложения и длинная история.
- В случае проблем v0.2.47 сохранена в резервной копии .tools/deployment-backups/pre-v0248-v0247.

Запрещено копирование cookies и токенов между Chromium и WebView2, отключение Happ или повторная отправка неопределённо доставленных сообщений.
