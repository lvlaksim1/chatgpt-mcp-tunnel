# ChatGPT MCP Tunnel v0.2.52 — WebView2 и постоянный административный доступ

Дата 31.10.2026 (МСК). DOMKAT.

## Архитектура
- Единственный пользовательский интерфейс переписки — полный веб-сайт chatgpt.com внутри WebView2, без WinForms RichTextBox, второй очереди сообщений, отдельного браузера и собственного дублирующего UI.
- Постоянный профиль WebView2 сохраняет авторизацию, диалоги и историю.
- Через Happ используется существующий локальный HTTP-прокси 127.0.0.1:10809; настройки VPN не изменяются.
- Тёмная цветовая палитра: #212121, #262626, #2f2f2f. CSS меняет только визуальные переменные/фон; не извлекает и не подменяет сообщения.
- Главный экран — чат, контекстное меню трея — «Настройки» и «Выход», статус трея краткий, настройки содержат подключение, уведомления, темы, передачу файлов, обновления, админ-доступ.
- Старый ChatWindow, WebViewChatHost, BrowserChatWorker и связанный код исключены из сборки, но сохранены в репозитории.
- Установщик по-прежнему поддерживает выбор повышения прав, автоматическое завершение старого экземпляра и обновление без зависания.

## Административная служба
- После одного UAC копирует установленный ChatGptMcpAgent.exe в защищённый Program Files и устанавливает ChatGptMcpAdmin как автоматическую службу LocalSystem.
- Named pipe ChatGptMcpAdminV1 ограничен ACL, реальным Windows SID и PID/path проверкой клиента ChatGptMcpTunnel.exe. Network SID запрещён.
- MCP shell.exec elevated=true направляется в службу без дальнейших UAC-подтверждений. При выключенной настроенной службе запрос не падает обратно на UAC, а выдаёт ошибку.
- Есть тайм-ауты, ограничение размера вывода, отмена при разрыве/STOP, аудит результата команды, кнопки первоначального включения и отзыва разрешения.
- Путь клиента остаётся стабильным при обновлении. Поскольку доверенный каталог программы может быть доступен владельцу Windows, полный захват авторизованной учётной записи остаётся вне границы защиты этой службы.
