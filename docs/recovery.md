# Автоматическое восстановление ChatGPT MCP Tunnel

С версии **0.2.11** программа обслуживает себя через задание Windows **ChatGPT MCP Tunnel Recovery**. Никакие дополнительные PowerShell-сценарии или отдельный диспетчер не требуются.

## Установка и удаление

При установке или обновлении установщик запускает `ChatGptMcpAgent.exe --watchdog-register`. Задание создаётся только для той установленной копии приложения, для которой пользователь включил автозагрузку. При отключённой автозагрузке задание отсутствует. Деинсталлятор выполняет `--watchdog-unregister` перед остановкой агента. Настройки в `%LOCALAPPDATA%\ChatGPTMCPAgent` сохраняются при обновлении.

## Логика

- Проверка проводится **каждые 2 минуты** и запускает встроенный режим `--watchdog-check`.
- Сверяются точные пути установки и имена процессов; сам проверяющий процесс не считается рабочим агентом.
- Если агент отсутствует два последовательных опроса и дочерних процессов тоже нет — запускается агент.
- Если агент существует, но **все** ожидаемые дочерние процессы отсутствуют четыре последовательных опроса — инициируется штатная остановка агента и его запуск.
- Между восстановительными действиями выдерживается **не менее 20 минут**.
- Внешние сетевые ошибки, отсутствие доступности OpenAI и проблемы проверки готовности не приводят к принудительному перезапуску.
- При неоднозначном результате исследования процессов (в том числе при недостаточных правах) восстановление не выполняется.
- Команда «Выход» в меню приложения создаёт паузу для восстановления. При следующем обычном запуске агента пауза снимается.
- Защита от параллельного исполнения: эксклюзивная блокировка файла.

## Диагностика

Журнал: `%LOCALAPPDATA%\ChatGPTMCPAgent\Watchdog\watchdog.log`.

Проверка политики без вмешательства в работающую программу:

```powershell
& 'D:\ChatGPTMCPAgent\ChatGptMcpAgent.exe' --test-watchdog
```

Ручная проверка процессов (запуск recovery-логики возможен только при подтверждённом отказе):

```powershell
& 'D:\ChatGPTMCPAgent\ChatGptMcpAgent.exe' --watchdog-check
```

За создание/удаление задания отвечают `--watchdog-register` и `--watchdog-unregister`, обычно вызываемые установщиком.

## Режимы проверки

Windows CI проверяет режим `--test-watchdog`, установку и удаление задания, сохранение при обновлении, а также совместимость с существующими способами установки клиента и сервера.

Испытание реального отказа проводится отдельно с контролируемой остановкой процесса; в штатной приемке достаточно тестов политики и регистрации, чтобы не прерывать активные команды пользователя.
