# ChatGPT MCP Tunnel v0.2.47 — браузерный чат (31.10.2026, MSK)

## Что работает
- Встроенное окно чата WinForms: новый чат, отправка текста, получение ответа, переключение локальных сессий.
- Обычный ChatGPT через отдельный авторизованный профиль Яндекс Браузера; browser-CDP, без API-ключа, Work/Codex и ручного MCP Apps-ретранслятора.
- Автоматическое закрепление URL /c/<uuid> за локальным ChatId, продолжение того же облачного контекста.
- Чтение актуального DOM ChatGPT 2026: h4[data-conversation-role=assistant] и data-markdown-text-style=assistant-message, с сохранением поддержки старых data-message-author-role.
- Устранено использование неавторизованной старой вкладки при создании нового чата.
- Восстановление отправленных сообщений без повтора, восстановление привязок после сбоя и перезапуска.
