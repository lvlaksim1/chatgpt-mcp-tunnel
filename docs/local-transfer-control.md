# Локальное управление передачей файлов (v0.2.10)

В v0.2.9 добавлен потоковый механизм передачи файлов и отображение прогресса. В v0.2.10 дополнительно появился **защищённый локальный канал управления**, позволяющий вызывать передачу из терминала и через имеющийся `shell.exec`, даже если подключённый плагин ещё не обновил список инструментов.

## Запуск через работающий Router Lite на DOMKAT

Команды выполняются в обычном терминале Windows **на сервере DOMKAT**. Используется уже установленный исполнительный модуль:

```powershell
$runtime = 'D:\ChatGPTMCPAgent\Runtime\ChatGptMcpTunnel.exe'
& $runtime --transfer start 'MKATUSHONOK' 'C:\Users\m.katushonok\Downloads\MAX.msi' 'DOMKAT' 'C:\Users\Maksim\Downloads\MAX.msi'
```

Результат содержит идентификатор `transfer_id`; файлы в ответ не возвращаются. Параметры компьютеров — имена из Router Lite; для сервера использовать `DOMKAT`. Если назначения уже существует, передача не заменяет его, а сообщает ошибку. Для разрешённой перезаписи добавляется `--overwrite`.

```powershell
& $runtime --transfer status
& $runtime --transfer status '<transfer_id>'
& $runtime --transfer cancel '<transfer_id>'
```

Команды возвращают JSON со скоростью, процентом выполнения, объёмом и состоянием. Интерфейс: значок приложения в трее DOMKAT → **Передача файлов**. Данные непосредственно передаются между компьютерами по действующему защищённому WSS, а не в чат и не через отдельный TCP-порт.

## Безопасность и восстановление

Внутренний управляющий канал реализован как **Windows Named Pipe** `ChatGptMcpTunnel.FileTransfers`, доступный только текущему пользователю Windows. Он запускается только в серверном режиме Router Lite. Пользователь на другом компьютере не может подключиться напрямую к этому каналу через сеть.

Файлы идут по установленному WSS с проверкой клиентского ключа и отпечатка TLS-сертификата. На получателе сохраняется временный файл, который переименовывается только после полной проверки SHA-256. При прерывании копирования и новом запуске с теми же параметрами передача продолжается с сохранённого смещения.

## Проверки

Автоматический тест `tests/test_file_transfer.py` проверяет также запуск через командную строку и локальный Named Pipe на изолированной паре Router Lite / клиентского агента. Пробные файлы: 15 МБ в обе стороны, файл 90 МБ, отмена и продолжение, защита от перезаписи, SHA-256. Для изоляции тестов от действующей программы задаётся отдельное имя канала `CHATGPT_MCP_TRANSFER_PIPE_NAME`.

Физический тест передачи `MAX.msi` с MKATUSHONOK на DOMKAT и проверка его SHA-256 должны фиксироваться отдельно.
