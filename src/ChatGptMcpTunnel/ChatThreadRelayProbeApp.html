Диагностика MCP Thread Relay

Сообщения из окна ChatGPT MCP Tunnel будут передаваться в этот диалог через ui/message. Никаких API-ключей, Codex и планировщика.

Подключение к MCP Apps…

Передача начинается автоматически, когда ChatGPT открывает этот MCP Apps-компонент. Отдельное нажатие «Начать передачу» не нужно. Кнопка теста — только для диагностики.

Эксперимент: компонент должен оставаться открытым в ChatGPT. Если ChatGPT приостановит или закроет его, передача сообщений остановится. Неотправленные сообщения сохранятся в локальной очереди.
