# Project goals

1. Make a standalone Windows-hosted MCP server accessible as a directly callable custom plugin from ChatGPT using OpenAI Secure MCP Tunnel.
2. Keep all project code, configuration, tests and release lifecycle in this independent repository.
3. Ensure secure credential handling, local auditing, permission enforcement and resilient lifecycle management before exposing powerful tools.
4. Provide reproducible installation, automated validation and a clean local working directory on drive D:.
5. Expand the MCP tool set only after independent authorization and security review; read-only connectivity was the first milestone.
