# Блокирующие вопросы и риски

- Список инструментов может быть закэширован на стороне конкретного чата ChatGPT; наличие 41 реализации в сервере само по себе не подтверждает их появление в этом чате.
- Переход со штатного GitHub-коннектора на собственный не завершён независимой проверкой всех необходимых рабочих сценариев.
- Графические тесты Windows требуют интерактивный рабочий стол; Калькулятор может показывать только корневой элемент в RawView и ControlView.
- При осмотре рабочей установки D:\ChatGPT-MCP-Tunnel выявлены два неотслеживаемых пользовательских файла; их содержимое не изучалось. Любая синхронизация работающего каталога должна сохранить их без изменений.

На проверенной исходной ревизии CI зелёный; это не доказывает постоянную доступность запущенного туннеля.
