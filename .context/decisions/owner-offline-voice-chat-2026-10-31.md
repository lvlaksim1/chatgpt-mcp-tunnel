# 31.10.2026 — обязательное решение владельца: локальный голосовой чат в MCP Tunnel

Статус: **утверждено к реализации в следующем обновлении v0.2.60** (после подтверждённой установленной v0.2.59). Владелец поручил выполнить разработку, тестирование, сборку и установку самостоятельно, пока он отсутствует.

## Цель
Полноценный голосовой ввод и вывод поверх действующего **авторизованного ChatGPT в WebView2**, без создания собственного текстового клиента и без использования нативного ChatGPT Voice. Голос и ручной текст работают в **текущем выбранном диалоге** с сохранением облачного контекста. Установленное подключение MCP, профиль авторизации, вкладки, тема и уведомления сохраняются.

## Договорённости 29 и 31 октября
- Обработка голоса **бесплатна, локальна, автономна**, без сторонних облачных Speech API и подписок.
- Распознавание: **Sherpa-ONNX**, русскоязычная модель (предпочтительно Zipformer; версию уточнять по модели), **Silero VAD** для границ фразы.
- Синтез: **Sherpa-ONNX TTS**, русскоязычная модель, воспроизведение локальными средствами Windows.
- Push-to-talk («удерживать кнопку») и непрерывное прослушивание; пауза определения конца фразы 300–1500 мс, по умолчанию 700 мс.
- Автоматическая отправка распознанного текста — настраиваемая; по умолчанию безопасный ручной режим до приёмки.
- Автоматическое озвучивание ответа — настраиваемое. Потоковое озвучивание законченных частей, если DOM WebView2 позволяет надёжно обнаружить завершение. Нельзя озвучивать предварительный текст повторно.
- Возможность прервать озвучивание новой командой (barge-in), защита от самопрослушивания синтезатора; предотвращение дублирующих отправок.
- Настройки: микрофон, динамики, голос, скорость речи, режим прослушивания, пауза, автоотправка, автоозвучивание. Хранить безопасные настройки между запусками.
- UI должен соответствовать тёплой тёмной теме, быть частью приложения, не подменять родной ChatGPT.
- Отдельный голосовой модуль для аудио + связь с активным WebView2. Разделять интерфейс/инференс/транспорт/настройки.
- Тестировать без реальной отправки приватных сообщений, пока не будет проверена доставка в правильный чат. Изолированные тесты + реальная приёмка на DOMKAT.
- **Установка только после проверки**, сохранить резервную копию v0.2.59, не убивать действующий транспорт; восстановить предыдущую версию при сбое. Установщик/обновление локально, GitHub как хранилище.
- Учитывать правило быстрых правок HTML/JS без переустановки (.context/decisions/owner-live-webview-ui-2026-10-31.md).

## Приёмка
Проверки: русский STT по реальному звуковому сигналу, русский TTS WAV/динамики, две последовательные реплики в одном обычном чате, корректная смена вкладки, контролируемая остановка, без повторных отправок, реакция на отсутствие микрофона, восстановление после перезапуска. Отдельно фиксировать: что фактически E2E протестировано, а что нельзя подтвердить без произнесённой владельцем фразы.

## Текущее основание
