## Топология и выбор
- DOMKAT и MKATUSHONOK физически находятся в разных локальных сетях; 192.168.0.3 — локальный адрес DOMKAT.
- Сохраняем один действующий OpenAI Secure MCP Tunnel, один проект/плагин Router Lite.
- Передача между компьютерами — Tailscale (WireGuard, сеть адресов 100.64.0.0/10); когда прямое соединение невозможно, Tailscale применяет зашифрованный ретранслятор.
- Непосредственно публиковать незащищённый WebSocket в Интернет или заводить ещё один облачный OpenAI туннель не нужно.
- WSS-ретранслятор/собственный сервер пока отклонён как избыточный для первого физического испытания.

## Реализовано
- Источник c04e2ec44c287d4f41ee4433f05b728609ed94ae: отдельная настройка брандмауэра только для конкретного Tailscale-адреса клиента и локального адреса сервера, с проверкой адаптера и явным подтверждением Windows UAC.
- Совместимость с прежней LAN-кнопкой сохранена. Клиент до этого уже принимал адреса Tailscale.
- Локальные сборка/selftests/RouterLite/reconnect прошли. GitHub Windows Actions 40756470762 — SUCCESS, выпущены стабильные установщики v0.2.7 с SHA256.

## Физическая приёмка
- Авторизация Tailscale на обоих ПК, VPN IP, установка v0.2.7 на живой DOMKAT и проверка соединения не выполнялись в этом изменении.
- Владелец должен завершить требующие учётной записи/Windows UAC шаги. После этого менеджер проверяет фактический удалённый MCP инструментальный доступ и только тогда закрывает требование.
