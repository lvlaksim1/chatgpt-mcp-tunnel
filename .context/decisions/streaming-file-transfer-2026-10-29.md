# Решение: потоковая передача больших файлов в Router Lite — 29.10.2026

**Источник полномочий:** прямое поручение владельца после неуспешной попытки передать `MAX.msi` с MKATUSHONOK на DOMKAT.

**Проблема:** прежний `fs.read` возвращает содержимое через MCP JSON, порождая огромные сообщения, ограничения по размеру и попадание двоичных данных в контекст. Замена скачиванием из Интернета не соответствует поручению копировать оригинал с удалённой машины.

**Принятое решение:**
- В новой версии v0.2.9 добавить отдельные `file.transfer.start/status/cancel` и внутренний протокол команд `inspect/read/prepare/append/finish`.
- Роутер выступает организатором, передаёт по 1 МиБ через уже авторизованное соединение WSS. Не требуется новый TCP-порт, сервер загрузки или стороннее облако. Двоичный файл никогда не возвращается в интерфейс ChatGPT.
- На приёмнике сохранять `.mcp-transfer.part` и проверяемые метаданные: длина и SHA-256; при совпадении продолжать с фактического размера промежуточного файла. Финальный файл появится только после проверки всего хеша.
- Запретить случайную перезапись существующего назначения, разрешать только с `overwrite=true`.
- Отражать процент, объём, скорость, ETA, состояние в `file.transfer.status` и в отдельном окне трея на сервере. Отмена оставляет промежуточный файл.
- Прерывание WSS обрабатывается попытками переподключения; после перезапуска процесса допускается продолжение новым `start`.

**Проверено в изолированном локальном Router Lite и агенте:** двунаправленная передача 15 МБ, защита назначения, отмена и возобновление, 90 МБ с идентичным SHA-256; прошли существующие Router Lite, MCP и WSS тесты; окно GUI успешно создаётся. **Внешняя физическая передача MKATUSHONOK → DOMKAT ещё не подтверждена**: оба устройства должны получить новую версию.

**Дальнейшие действия:** публикация сборки v0.2.9, обновление обеих машин, передача исходного `MAX.msi` (324820992 байт), сверка SHA-256 `14A528C373B19B35B3C9E77B5FAEE88DC34A073F15D8801673DDB7C040B2D48F`, проверка окна прогресса. Устанавливать MAX в рамках разработки механизма пока не требуется.
